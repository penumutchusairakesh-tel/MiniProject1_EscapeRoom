Escape Room

A text-based escape room game created using Python.

About:
    The player is stuck inside a house. Needs to explore different rooms find clues solve puzzles collect numbers for a password and use them to open the main door.

    The game has rooms, locked areas, puzzles that require a password, an inventory system, a limited number of lives and various ways to find clues.
